# JChemPaint — Chemical Structure Editor

Course outline for the JChemPaint module of the chemistry software syllabus.

## Topics covered

1. Introduction to JChemPaint: what JChemPaint is, chemical structure editor,
   installing JChemPaint, Java runtime, launching the application, the JChemPaint
   window, menu bar, tool bar, drawing area, status bar, periodic table panel.
2. Drawing structures: bond, single bond, double bond, triple bond, up bond, down bond,
   bond length, bond angle, atom, element symbol, carbon, hydrogen, oxygen, nitrogen,
   sulphur, chlorine, benzene ring, cyclohexane, cyclopentane, ring, template,
   chain, draw chain, hexagon, structure, molecule, compound, functional group.
3. Editing structures: select, move, rotate, flip horizontal, flip vertical, delete,
   undo, redo, cut, copy, paste, zoom in, zoom out, drag, click and drag, eraser.
4. Properties of JChemPaint: molecular formula, molecular weight, molecular mass,
   atom properties, charge, positive charge, negative charge, lone pair, isotope,
   implicit hydrogen, explicit hydrogen, valency, stereochemistry, wedge, hash,
   R group, atom label, pseudo atom.
5. Features of JChemPaint: file formats, MDL molfile, mol file, CML, chemical markup
   language, SMILES, InChI, save as, export image, PNG, JPEG, SVG, print,
   generate 2D coordinates, clean structure, structure validation.
6. Applications: drawing reaction schemes, reactant, product, arrow, plus sign,
   reaction, organic chemistry, chemical equation, lab report, publication quality
   diagram.

## Environment

GNU/Linux, Ubuntu Linux, Java, JRE, open source chemistry software, Chemistry
Development Kit, CDK.
