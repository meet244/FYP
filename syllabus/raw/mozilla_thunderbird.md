# Mozilla Thunderbird — Email Client

Course outline for the Mozilla Thunderbird module of the digital literacy syllabus.

## Topics covered

1. Introduction to Mozilla Thunderbird: what an email client is, installing Thunderbird
   from the Ubuntu Software Centre, launching Thunderbird, the Thunderbird window,
   folder pane, message list pane, message pane, toolbar, menu bar, status bar.
2. Configuring an email account: account settings, mail account setup wizard, your name,
   email address, password, incoming server, outgoing server, IMAP, POP, SMTP,
   port number, SSL, TLS, authentication, server name, username, manual configuration,
   create account, Gmail account, Yahoo account, webmail.
3. Using Thunderbird: compose, write, send, reply, reply all, forward, attachment,
   attach file, subject, to, cc, bcc, address, message body, signature, draft, send
   later, inbox, sent, drafts, trash, junk, archive, spam filter, delete, mark as read,
   mark as unread, star, flag.
4. Address book: contacts, personal address book, collected addresses, new contact,
   new list, mailing list, edit contact, delete contact, import contacts, export
   contacts, CSV file, LDIF, search contacts, display name, nickname, organisation,
   phone number.
5. Organising mail: folders, new folder, move to folder, copy to folder, message
   filters, filter rules, search messages, quick filter, sort by date, sort by sender,
   threads, tags, labels.
6. Settings and preferences: account settings, server settings, composition and
   addressing, junk settings, synchronisation and storage, offline mode, return receipt,
   check for new messages, leave messages on server.

## Environment

GNU/Linux, Ubuntu Linux, Mozilla Thunderbird, internet connection, web browser,
Firefox, Gmail, Google account.
