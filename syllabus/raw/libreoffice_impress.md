# LibreOffice Impress — Presentation Software

Course outline for the LibreOffice Impress module of the office productivity syllabus.
Lectures are delivered in Hindi with English technical vocabulary.

## Topics covered

1. Introduction to LibreOffice Impress: the Presentation Wizard, slide layouts, and the
   Impress window. Parts of the window: Slides pane, Workspace, Tasks pane, Sidebar,
   Standard toolbar, Drawing toolbar, Status bar.
2. Creating a presentation document and basic formatting: insert slide, duplicate slide,
   delete slide, copy and paste slides, Outline view, Title Slide layout, Title Content
   layout, bullet and numbering, font name, font size, font colour, bold, italic,
   underline, alignment, line spacing.
3. Views: Normal view, Outline view, Notes view, Handout view, Slide Sorter view.
4. Slide Master and slide design: master slide, master pages, background, background
   image, template, style, presentation styles, graphic styles, header and footer,
   date and time, slide number.
5. Presentation notes: speaker notes, Notes pane, notes page layout, printing notes.
6. Custom animation: animation effects, Entrance, Emphasis, Exit, Motion Path, effect
   options, start on click, start with previous, start after previous, speed, delay,
   slide transition, transition effect, advance slide, automatic transition, rehearse
   timings.
7. Viewing a presentation: slide show, start from first slide, start from current slide,
   presenter console, navigation, escape key, full screen.
8. Printing a presentation: print dialog, print range, handouts, slides per page,
   print preview, grayscale, black and white, PDF export, page setup, orientation,
   portrait, landscape, paper size.

## Common commands and interface terms

File, Edit, View, Insert, Format, Slide, Slide Show, Tools, Window, Help, Save As,
Open, Close, Undo, Redo, Cut, Copy, Paste, Zoom, Ctrl S, Ctrl Z, right click,
double click, drag and drop, dialog box, checkbox, dropdown, toolbar, context menu.

## File formats

odp, ODF Presentation, ppt, pptx, PowerPoint, pdf, export, import, template file otp.

## Environment

GNU/Linux, Ubuntu Linux, LibreOffice Suite version 3.3.4, operating system.
