# GNU/Linux Basics and the Shell

Course outline for the GNU/Linux fundamentals module.

## Topics covered

1. The operating system: kernel, shell, distribution, Ubuntu, Fedora, desktop
   environment, GNOME, Unity, login, logout, user account, root, sudo, password,
   package manager, apt, apt-get, Software Centre, install, update, upgrade.
2. The file system: root directory, home directory, path, absolute path, relative path,
   hidden file, permission, read, write, execute, owner, group, others, chmod, chown,
   file, directory, folder, symbolic link.
3. Basic commands: ls, cd, pwd, mkdir, rmdir, cp, mv, rm, cat, less, more, head, tail,
   touch, find, locate, grep, wc, sort, uniq, diff, echo, man, help, history, clear,
   exit, whoami, date, cal, df, du, ps, top, kill, chmod.
4. The terminal: terminal window, command prompt, dollar prompt, Ctrl Alt T,
   command line, argument, option, flag, pipe, redirection, standard input,
   standard output, standard error, wildcard, asterisk, tab completion.
5. Text processing: text editor, gedit, vim, nano, redirect output to file,
   append, pipe to grep, search text, regular expression, pattern.
6. Shell scripting basics: shell script, bash, shebang, variable, echo, read,
   if condition, for loop, while loop, function, exit status, executable permission,
   run a script, dot slash.

## Environment

GNU/Linux, Ubuntu Linux, bash shell, terminal, free and open source software.
