# Scilab — Numerical Computation

Course outline for the Scilab module of the scientific computing syllabus.

## Topics covered

1. Getting started: Scilab console, command window, file browser, variable browser,
   command history, editor, SciNotes, script file, sce file, sci file, execute,
   clc, clear, who, help, apropos, comment, semicolon.
2. Variables and matrices: scalar, vector, row vector, column vector, matrix,
   matrix operations, transpose, inverse, determinant, det, inv, rank, eye, zeros,
   ones, rand, size, length, element wise operation, dot operator, colon operator,
   linspace, indexing, submatrix.
3. Operators and functions: arithmetic operators, relational operators, logical
   operators, sin, cos, tan, exp, log, sqrt, abs, sum, prod, max, min, mean, round,
   floor, ceil, modulo.
4. Programming: if else, select case, for loop, while loop, break, continue,
   function definition, endfunction, deff, arguments, output arguments, recursion,
   script versus function, disp, printf, input.
5. Plotting: plot, plot2d, xlabel, ylabel, title, legend, subplot, grid, axis,
   histplot, bar, surf, contour, figure, clf, export graph.
6. Applications: solving linear equations, polynomial, roots, curve fitting,
   numerical integration, differential equation, ode solver, Xcos, simulation, block.

## Environment

GNU/Linux, Ubuntu Linux, Scilab version 5, open source alternative to MATLAB.
