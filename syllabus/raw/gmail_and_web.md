# Email, Gmail and Web Basics

Course outline for the internet and email module of the digital literacy syllabus.

## Topics covered

1. Email fundamentals: email address, username, domain, at the rate, inbox, outbox,
   compose, send, receive, reply, reply all, forward, attachment, subject line,
   signature, spam, junk mail, phishing, contact, mailing list.
2. Gmail: Google account, sign in, sign up, password, two step verification,
   Gmail settings, labels, filters, starred, important, snooze, archive, delete,
   trash, storage, search mail, chat, Google Drive, Google Docs, Google Calendar.
3. Configuring Gmail with a desktop client: account settings, enable IMAP,
   enable POP, forwarding and POP IMAP tab, server settings, incoming mail server,
   imap.gmail.com, outgoing mail server, smtp.gmail.com, port, SSL, TLS,
   application specific password, less secure apps, synchronisation, offline access.
4. Web browsing: web browser, Firefox, Chrome, URL, address bar, website, web page,
   hyperlink, tab, bookmark, history, download, search engine, Google, refresh,
   back button, forward button, home page, https, secure connection, certificate.
5. Online safety: strong password, do not share password, log out, public computer,
   antivirus, software update, personal information, privacy setting.

## Environment

GNU/Linux, Ubuntu Linux, web browser, internet connection, Mozilla Thunderbird, Gmail.
