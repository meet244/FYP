# LaTeX — Document Preparation

Course outline for the LaTeX module of the technical documentation syllabus.

## Topics covered

1. Introduction: what LaTeX is, typesetting system, source file, tex file, compile,
   pdflatex, latex, dvi, ps, pdf, editor, TeXworks, gedit, terminal, preamble,
   document class, article, report, book, begin document, end document.
2. Basic formatting: section, subsection, subsubsection, chapter, paragraph, title,
   author, date, maketitle, table of contents, newpage, line break, textbf, textit,
   underline, emph, footnote, quotation, verbatim, font size commands.
3. Lists and tables: itemize, enumerate, description, item, nested list, tabular,
   column specification, hline, multicolumn, caption, label, table environment,
   centering.
4. Mathematics: math mode, inline math, dollar sign, displaymath, equation environment,
   align, fraction, frac, square root, sqrt, superscript, subscript, summation, sum,
   integral, int, limit, Greek letters, alpha, beta, gamma, theta, matrix, amsmath.
5. Figures and references: includegraphics, graphicx package, figure environment,
   caption, label, ref, cite, bibliography, bibtex, cross reference, hyperref, url.
6. Packages and errors: usepackage, package, compile error, missing brace,
   undefined control sequence, log file, aux file, rerun to get references right.

## Environment

GNU/Linux, Ubuntu Linux, TeX Live, terminal, PDF viewer, Xfig export to LaTeX.
