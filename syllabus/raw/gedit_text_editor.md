# gedit Text Editor

Course outline for the gedit text editor module of the GNU/Linux tools syllabus.

## Topics covered

1. Introduction to gedit text editor: opening gedit, the gedit window, menu bar,
   toolbar, editing area, status bar, side panel, bottom panel, creating a new file,
   opening a file, saving a file, save as, recent files, print, undo, redo, cut, copy,
   paste, find, replace, go to line, word wrap, line numbers, text wrapping,
   syntax highlighting, highlight mode, colour scheme, font, preferences.
2. Handling tabs: tabs and spaces, tab width, insert spaces instead of tabs,
   automatic indentation, auto indent, tab stops, multiple tabs, new tab, close tab,
   move tab to new window, switch between tabs, tab group, drag tab.
3. Default plugins: plugin, enable plugin, disable plugin, plugins tab in preferences,
   Document Statistics, External Tools, File Browser Panel, Insert Date and Time,
   Modelines, Python Console, Quick Open, Snippets, Sort, Spell Checker,
   Tag List, Change Case, word count, line count, character count.
4. Snippets: snippet, create a snippet, activation, tab trigger, shortcut key,
   drop targets, snippet manager, insert snippet, edit snippet, global snippets,
   language specific snippets, placeholder, variable, python snippet, html snippet,
   c snippet, latex snippet, reuse code.
5. Working with code: writing a C program in gedit, saving with an extension,
   opening a terminal, compiling from the terminal, editing configuration files,
   read only file, permission denied, sudo, root, backup copy.

## Environment

GNU/Linux, Ubuntu Linux, gedit version 3, terminal, Ctrl Alt T, Ctrl S, Ctrl N,
Ctrl O, Ctrl W, Ctrl Q, Ctrl F, Ctrl H, home directory, file path, extension.
