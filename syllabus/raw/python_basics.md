# Python Programming Basics

Course outline for the introductory Python module.

## Topics covered

1. Getting started: python interpreter, ipython, interactive shell, script, running a
   program, print function, comment, indentation, colon, block.
2. Data types: int, float, string, boolean, complex, list, tuple, dictionary, set,
   type function, type conversion, immutable, mutable.
3. Operators and expressions: addition, subtraction, multiplication, division,
   floor division, modulus, exponent, comparison operators, logical operators,
   and, or, not, membership operator, in.
4. Control flow: if, elif, else, for loop, while loop, range, break, continue, pass,
   nested loop, iteration.
5. Functions and modules: def, return, arguments, keyword arguments, default value,
   lambda, import, from import, module, package, standard library, math module,
   os module, sys module.
6. Strings and files: string methods, split, join, strip, replace, format, f string,
   slicing, open file, read, write, append, with statement, close.
7. Plotting and scientific computing: numpy, array, matplotlib, pyplot, plot, xlabel,
   ylabel, title, legend, show, savefig, scipy, pandas, dataframe, csv.
8. Errors and debugging: syntax error, indentation error, name error, type error,
   index error, exception, try, except, finally, traceback, debugging.

## Environment

GNU/Linux, Ubuntu Linux, Python 3, ipython, terminal, text editor, jupyter notebook.
