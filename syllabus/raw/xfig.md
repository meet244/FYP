# Xfig — Vector Drawing for Technical Diagrams

Course outline for the Xfig module of the technical documentation syllabus.

## Topics covered

1. Introduction to Xfig: what Xfig is, vector graphics, drawing tool, installing xfig,
   launching xfig from the terminal, the xfig window, drawing canvas, side toolbar,
   top toolbar, indicator panel, mouse buttons, left button, middle button,
   right button, snap to grid, grid, ruler, zoom.
2. Drawing objects: line, polyline, polygon, box, rectangle, circle, ellipse, arc,
   spline, open spline, closed spline, arrow, arrow head, text object, picture object,
   library object, regular polygon.
3. Object properties: line width, line style, dashed line, dotted line, fill colour,
   pen colour, fill style, depth, layer, join style, cap style, arrow type,
   text size, text font, text justification, angle, rotation.
4. Editing: move object, copy object, delete object, scale, rotate, flip, align,
   glue, break compound, compound object, edit properties, undo, redo, update,
   change object.
5. Block diagrams: block diagram, box with text, connecting lines, arrows between
   blocks, labels, input, output, system block, signal flow, alignment of blocks,
   spacing, layout.
6. Feedback diagrams: feedback diagram, control system, summing junction, feedback
   loop, forward path, feedback path, transfer function, plant, controller, sensor,
   negative feedback, positive feedback, closed loop, open loop, block, arrow direction.
7. Embedding mathematics in Xfig: LaTeX text flag, special text, equation, formula,
   mathematical symbol, subscript, superscript, Greek letter, alpha, beta, theta,
   summation, integral, fraction, exporting to LaTeX, combined ps and latex,
   pstex, pstex_t, eps, encapsulated postscript, pdf export, compile with latex,
   dvi file, include graphics.

## Environment

GNU/Linux, Ubuntu Linux, xfig, LaTeX, terminal, fig file format, export, print.
