# LibreOffice Writer — Word Processing

Course outline for the LibreOffice Writer module. Delivered in Hindi with English
technical vocabulary.

## Topics covered

1. Introduction to LibreOffice Writer: the Writer window, menu bar, standard toolbar,
   formatting toolbar, ruler, status bar, document area, scroll bar.
2. Typing text and basic formatting: font name, font size, bold, italic, underline,
   font colour, highlighting colour, superscript, subscript, align left, align right,
   centered, justified, bullets and numbering, increase indent, decrease indent,
   line spacing, paragraph spacing, character formatting, paragraph formatting.
3. Find and Replace: search term, replace with, replace all, match case, whole words
   only, regular expressions, similarity search, AutoCorrect, autocorrect options,
   autocomplete, word completion, spell check, spelling and grammar, thesaurus,
   language settings.
4. Newsletters with columns: page style, format page, columns, column width, spacing,
   separator line, section, insert section, text flow, column break, page break,
   drop cap, text wrap, image anchoring, wrap around, caption.
5. Viewing and printing documents: print preview, web view, normal view, zoom,
   full screen, print dialog, printer properties, number of copies, page range,
   print all pages, print selection, paper size, margins, orientation, portrait,
   landscape, header, footer, page number, PDF export.
6. Track changes and peer review: record changes, track changes, edit document,
   peer review, reviewer, accept change, reject change, accept all, reject all,
   comment, insert comment, delete comment, manage changes, show changes, merge
   document, compare document, version, author, changed text, strikethrough.
7. Tables, lists, and styles: insert table, rows, columns, merge cells, split cells,
   table borders, paragraph style, character style, heading 1, heading 2, default style,
   apply style, style and formatting window, template.

## Common commands and interface terms

File, Edit, View, Insert, Format, Table, Tools, Window, Help, New, Open, Save, Save As,
Export as PDF, Undo, Redo, Cut, Copy, Paste, Paste Special, Select All, Ctrl A, Ctrl C,
Ctrl V, Ctrl P, Ctrl F, dialog box, checkbox, dropdown, tab, right click, cursor.

## File formats

odt, ODF Text Document, doc, docx, Microsoft Word, rtf, txt, pdf, html.

## Environment

GNU/Linux, Ubuntu Linux, LibreOffice Suite version 3.3.4, operating system.
