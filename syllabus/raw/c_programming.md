# C and C++ Programming

Course outline for the introductory C/C++ programming module. Lectures are delivered in
Hindi with English technical vocabulary and live coding demonstrations.

## Topics covered

1. First C program: header file, stdio.h, include, main function, return statement,
   printf, scanf, compile, execute, gcc, terminal, source code, object file,
   executable file, semicolon, curly brackets, comment.
2. Data types and variables: int, float, double, char, long, short, signed, unsigned,
   variable declaration, initialisation, constant, format specifier, percent d,
   percent f, percent c, percent s, type casting, sizeof operator.
3. Operators: arithmetic operators, relational operators, logical operators,
   assignment operator, increment, decrement, modulus, bitwise operators,
   ternary operator, precedence, associativity.
4. Control structures: if statement, if else, nested if, else if ladder, switch case,
   break, default, for loop, while loop, do while loop, continue, nested loop,
   infinite loop, condition, iteration.
5. Functions: function declaration, function definition, function call, prototype,
   arguments, parameters, return type, void, call by value, call by reference,
   recursion, scope, local variable, global variable.
6. Storage class specifiers: auto, register, static, extern, storage class, lifetime,
   visibility, scope, memory, stack, default value, garbage value.
7. Arrays and strings: array declaration, index, subscript, one dimensional array,
   two dimensional array, string, character array, null character, strlen, strcpy,
   strcat, strcmp, array of strings.
8. Pointers: pointer variable, address of operator, dereference, pointer arithmetic,
   null pointer, pointer to pointer, dynamic memory allocation, malloc, calloc, free.
9. Structures, typedef and union: struct, structure member, dot operator, arrow
   operator, nested structure, typedef, user defined data type, union, memory sharing,
   size of structure, size of union, keyword.
10. Command line arguments: argc, argv, argument count, argument vector, main with
    arguments, passing arguments at run time, atoi, command line, executable name.
11. File handling: FILE pointer, fopen, fclose, fprintf, fscanf, fgets, fputs, read
    mode, write mode, append mode.

## Environment

GNU/Linux, Ubuntu Linux, gcc compiler, g++ compiler, gedit editor, terminal,
Ctrl Alt T, command prompt, dollar prompt.
